# 漢字おじゃまLIVE — 既存利用者向け更新配布

この公開リポジトリは、既に **KOJ＋NGL ギフト連携 R1S31** を使用している方向けの更新配布専用です。公開リポジトリのため、ファイルは誰でも取得できますが、新規導入用の完全セットではありません。

## 初回の R1S31 → R1S32

配信を終えてKOJとNGLを閉じ、Releaseの `KanjiOjamaLIVE_GiftBundle_R1S32.zip` を取得してください。ZIPは展開せず、既存R1S31フォルダの「アップデート.cmd」へドラッグします。別の新規フォルダへ展開して使う手順ではありません。既存フォルダへのZIP直接上書きはしないでください。

R1S31はオンライン確認先が未設定のため、この初回のみローカルZIPによる移行が必要です。R1S32へ移行した後は「アップデート.cmd」のダブルクリックで、このリポジトリのReleaseから最新情報を確認します。同じ版なら更新しません。利用する版の公開・オンライン確認状況はReleaseの説明を確認してください。

## 引き継ぐものと含めないもの

公開ZIPにはTikTok由来のギフト画像696件と予備WAV2件を同梱していません。更新時は既存環境の一致したファイルだけを、このPC内で引き継ぎます。これらのローカル素材や利用者設定がGitHubへ送られる仕組みではありません。ZIPを単独展開した場合や引継ぎ元が不足する場合、画像なし等の代替表示になります。

更新前の版は保持されます。「前の版に戻す.cmd」で、整合性を確認した前の版へ戻せます。利用者の設定・記録を消す方法ではありません。復旧に失敗した場合はアプリを起動せず、更新器の結果とログを確認してください。

## 再試行と検証状態

同じ失敗取引の自動再試行は無効です。`retry_policy` の `PENDING_PM_APPROVAL` はその制限を表し、利用者が書き換えるものではありません。「再認可が必要」と表示されたら同じ操作を繰り返さず、配布者へ連絡してください。

初回の公開直後は、実GitHub経路による確認が未完了の場合があります。Release説明の「オンライン確認結果」を参照してください。検証前にオンライン実動作確認済みとは案内しません。同梱案内の候補・正式CURRENT未変更という記述は、全製品の正式受入れを意味しない状態として残しています。本リポジトリで提供するのは、既存利用者向けの限定更新配布です。

第三者ライセンスと通知は配布物内にあります。libvips等の対応ソースは、同じR1S32 Releaseの `KanjiOjamaLIVE_R1S32_libvips-8.15.3_corresponding_source.zip` に含まれます。GitHubが自動生成する「Source code」アーカイブとは別物です。必要なソースと通知を保持し、第三者のライセンスが認める変更・再リンク等を妨げません。プロジェクト全体を一律にMIT等へ変更するものではありません。

このプロジェクトはTikTokその他の第三者の公式・公認ソフトウェアではありません。残るギフト名・ID・価格等のデータについて、プラットフォームから包括的な再配布許諾を取得したという表示はしません。プラットフォームの利用規約、とくに自動取得・通信に関する適用条件は別の事項で、今回の配布許可がそれらを上書きするものではありません。
